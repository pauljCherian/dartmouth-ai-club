  • Every page. No sideways scrolling, no clipped text, no script or loading errors.
  • Accessibility. Automated audit (axe, WCAG 2.2 AA) found no violations on any page, desktop or phone. Every standalone link and button is at least 24 px tall on touch screens.
  • Phone menu. Tested on 7 small screens: focus moves into the menu, the page behind is locked, Escape closes it and returns focus to the button.
  • Smoothness. With the processor slowed 4×, scrolling through the hand-off: 95% of frames under 19 ms (60 fps is 16.7 ms), 0 dropped frames over 33 ms, layout shift 0.
  • Fallbacks. Reduced motion and no JavaScript get the static layout with the logo visible; high-contrast (forced colors) mode keeps buttons, markers and the menu icon visible. Printing gives the static layout with no blank pages.
  • Zoom and text settings. At 400% zoom the home page switches to the static layout; with the WCAG text-spacing settings on 12 screen sizes, the tagline never touches the title; with the browser's default text at 20 or 24 px, no page scrolls sideways or clips text.
