# Dartmouth AI Club website

The site at [aiclub.dartmouth.edu](https://aiclub.dartmouth.edu). Plain HTML, CSS and a little JavaScript, generated by a small build script with no dependencies. Vercel builds and hosts it.

## Change the content

Everything people read lives in `content/`. Edit the JSON, commit, push. Vercel rebuilds the site.

| File | What it holds |
| --- | --- |
| `content/site.json` | Tagline, contact email, meeting time and place, member count, join form link, social links, hero caption, and claims to confirm (delete one under `claims` to remove it from every page) |
| `content/speakers.json` | Every guest talk. The site sorts them by date; the earliest talk that hasn't ended is shown as "Next" |
| `content/sessions.json` | Member sessions (weekly talks) with slides and paper links |
| `content/team.json` | Officers and faculty advisors |
| `content/reading.json` | The reading list |

### Add a speaker

Add an entry to `content/speakers.json` (anywhere; the top is easiest):

```json
{
  "id": "first-last",
  "name": "First Last",
  "role": "Research at",
  "org": "Company",
  "format": "Fireside chat",
  "title": "Talk title (optional)",
  "start": "2027-01-19T20:00:00-05:00",
  "end": "2027-01-19T21:30:00-05:00",
  "date_label": "Tue Jan 19, 2027",
  "time_label": "8 pm",
  "place": "ECSC 116",
  "photo": "first-last",
  "photo_alt": ""
}
```

- `start` and `end` need New York's offset for that date: `-04:00` from the second Sunday in March to the first Sunday in November, `-05:00` the rest of the year. The build checks it, that the date exists, that `end` is after `start`, and that the event lasts at most 3 days.
- `date_label` must match `start`: "Nov 6, 2026", with an optional weekday first ("Fri Nov 6, 2026", "Friday, November 6, 2026"). `time_label`, if set, must match the start time: "4 pm", "4:30 pm", "4 p.m." or a range like "4–5:30 pm". The build stops if either disagrees, so a rescheduled talk can't keep its old label.
- A talk counts as upcoming until `end`, or two hours after `start` if there is no `end`. The page switches it to "past" in the visitor's browser when it ends (on load, or live if the page is open), even before the next build.
- The home page shows the next talk and the six most recent past ones. `/speakers` shows every talk.
- `role` is shown in gray and `org` in bold, as on the posters: "Research at **Meta Superintelligence Labs**".
- `photo_alt`: leave it `""` for a plain head-and-shoulders portrait (the name is printed right next to it, so screen readers would hear it twice). Describe the photo only when it shows more, such as the speaker at the event.

### Add or replace a photo

Photos go through one script, so every face gets the same crop and the same ink-and-paper tone. It needs Python 3 with Pillow and numpy (`pip install pillow numpy`).

1. Put the original in `assets-src/people/` (or `assets-src/hero/hero.jpg` for the group photo).
2. Add or edit its line in `content/photos.json`. `crop` is a 4:5 box in the original's pixels, `x,y,w,h`: eyes about 40% from the top, head about 55-60% of the box height.
3. Run:

```bash
python3 tools/images.py all
```

That rebuilds every image in `public/img/` in AVIF, WebP and JPEG, never upscales, converts to sRGB, and strips all metadata including location. People without a usable photo are listed under `missing` and get a neutral initials tile on the site. Any other `photo` id without an image stops the build, so a typo can't slip through.

For the group photo, `hero.ceiling` in `content/photos.json` is the fraction of its height, measured from the top, that is only ceiling (0.18 now; the highest head starts at about 0.215). Wide screens crop that much and no more, and get margins beyond it. Measure it again if the photo changes.

## Build and look at it locally

Needs Node 18 or newer. Nothing to install.

```bash
npm run dev
```

That builds `dist/` and serves it at http://localhost:4321, on this computer only, with the same clean URLs, redirects and headers as Vercel. Other commands:

```bash
npm run build      # production build into dist/
npm run preview    # preview into preview/ (inlined CSS, JS and fonts; links end in .html). preview/index.html is a
                   # fragment for the Claude artifact viewer, which supplies the page frame; open the other pages directly.
BUILD_NOW=2026-11-07T12:00:00-05:00 npm run build   # pretend it is another date
ALLOW_MISSING=1 npm run build      # development only: placeholders for missing fonts and portraits instead of stopping
```

The build stops with a list of problems if content is invalid (including a talk time with the wrong offset), a photo or font is missing, or any internal link, anchor, icon or redirect target is broken.

## Deploy

Vercel reads `vercel.json`: build command `node tools/build.mjs`, output `dist/`, clean URLs, and permanent redirects from the old pages (`/meeting-materials`, `/resources`, `/reading-lists`). Every branch pushed to GitHub gets its own preview URL. Merging into `main` publishes to aiclub.dartmouth.edu. Fonts are published under names that include a hash of their contents, so browsers can keep them for a year and still get a replaced font at once.

### Optional: rebuild every morning

Visitors' browsers already move a talk from "Next" to past when it ends. A daily rebuild also updates what doesn't run JavaScript: the event data search engines read, and visitors with JavaScript off. To set it up, create a deploy hook for `main` in Vercel (Project, Settings, Git, Deploy Hooks), save its URL in GitHub as the Actions secret `VERCEL_DEPLOY_HOOK`, and add `.github/workflows/rebuild.yml`:

```yaml
name: Daily rebuild
on:
  schedule:
    - cron: '17 10 * * *'   # 10:17 UTC, early morning in Hanover
  workflow_dispatch:
jobs:
  rebuild:
    runs-on: ubuntu-latest
    steps:
      - run: curl -fsS -X POST "$HOOK"
        env:
          HOOK: ${{ secrets.VERCEL_DEPLOY_HOOK }}
```

## Design rules

- **Colour.** Paper `#F4F4F1`, ink `#161616`, gray `#666662`, hairlines `#D9D9D4`. Never pure white or pure black. Dartmouth Green `#00693E` marks things you can act on (the Join links and button, link hover, keyboard focus, selection) and numbered markers. Nowhere else.
- **Type.** One family, two weights. Helvetica on Apple devices and TeX Gyre Heros (a free Helvetica clone) everywhere else, through the single family name `Club Sans` in `src/styles/site.css`.
- **Logo.** `src/svg/logo-display.svg` (hero size: tighter letter-spacing and leading) and `src/svg/logo-small.svg` (header and footer: looser, so the lines never touch). They are drawn outlines, so they look identical on every device. Never retype the logo as live text.
- **Arrow.** `src/svg/arrow-e.svg` and `arrow-ne.svg` are the only icons. → goes somewhere on this site; ↗ leaves it.
- **Motion.** One choreographed moment: the hand-off on the home page. Native scrolling, the browser's own cursor, nothing fading in on scroll. People who ask their device for reduced motion get the static layout.

## Folders

```
content/        what the site says (edit these)
src/pages/      one file per page
src/lib/        shared header, footer, layout and helpers
src/styles/     site.css
src/scripts/    site.js (hand-off, mobile menu, upcoming talks)
src/svg/        logo lockups and arrows
public/         copied as-is: fonts, images, icons
tools/          build.mjs, serve.mjs, images.py
assets-src/     metadata-free originals of the photos (not published)
```
