# Dartmouth AI Club website

The site at [aiclub.dartmouth.edu](https://aiclub.dartmouth.edu). Plain HTML, CSS and a little JavaScript, generated by a small build script with no dependencies. Vercel builds and hosts it.

## Change the content

Everything people read lives in `content/`. Edit the JSON, commit, push. Vercel rebuilds the site.

| File | What it holds |
| --- | --- |
| `content/site.json` | Tagline, contact email, member count, join form link, social links, hero caption, and claims to confirm (`build_nights` and `majors`, each with its `source`; delete one under `claims` to remove it from every page). There is no meeting time or room on purpose: they change every term, so the site sends people to the GroupMe for them |
| `content/speakers.json` | Every guest talk: who they are, what they do, when they came. The site sorts them by date |
| `content/team.json` | Officers and faculty advisors |

### Add a speaker

Add an entry to `content/speakers.json` (anywhere; the site sorts by date). Every talk shows the same things: their photo, who they are, what they do, and when they came.

```json
{
  "id": "first-last",
  "name": "First Last",
  "role": "Head of Research, Company",
  "description": "One plain line on what they work on, under about 90 characters.",
  "date": "2027-01-19",
  "photo": "first-last",
  "photo_alt": ""
}
```

- `role`: their role and organisation **at the time of the talk**, as one line ("Head of Data, Simile"). Never "Formerly at…": the list is a record of who came, so it never needs updating when people move on.
- `description`: required, one plain line about the person's own work (not their company's slogan).
- `date`: the day of the talk. You can add a talk before it happens: it stays hidden until that day is over in New York, decided in the visitor's browser, so nobody has to remember to update the site afterwards.
- The home page shows the six most recent talks; `/speakers` shows every talk, grouped by year.
- `photo_alt`: leave it `""` for a plain head-and-shoulders portrait (the name is printed right next to it, so screen readers would hear it twice). Describe the photo only when it shows more, such as the speaker at the event.
- `photo_credit` (only for a photo whose licence asks for a credit, e.g. from Wikimedia Commons): `{"by": "Photographer", "source": "https://…", "license": "CC BY-SA 2.0", "license_url": "https://…"}`. The credit line is shown wherever the photo appears.

### Add or replace a photo

Photos go through one script, so every face gets the same crop and the same ink-and-paper tone. It needs Python 3 with Pillow and numpy (`pip install pillow numpy`). iPhone originals (`.heic`) also need `pip install pillow-heif`; without it, export the photo as a JPEG at full size.

1. Put the original in `assets-src/people/` (or `assets-src/hero/hero.jpg` for the group photo). Phone photos carry the location where they were taken, and `assets-src/` is committed, so copy them in with the script, which writes an upright JPEG with no metadata at all:
   - a portrait: `python3 tools/images.py original ~/Downloads/IMG_1234.HEIC assets-src/people/first-last.jpg`
   - the group photo: `python3 tools/images.py original ~/Downloads/IMG_0412.HEIC assets-src/hero/hero.jpg --force` (`--force` because it replaces the current one)
2. Add or edit its line in `content/photos.json`. `crop` is a 4:5 box in the original's pixels, `x,y,w,h`: eyes about 40% from the top, head about 55-60% of the box height.
3. Run:

```bash
python3 tools/images.py all
```

That rebuilds every image in `public/img/` in AVIF, WebP and JPEG, and the link-preview image `public/og.jpg` (the group photo beside the logo), never upscales, converts to sRGB, and strips all metadata including location. People without a usable photo are listed under `missing` and get a neutral initials tile on the site. Any other `photo` id without an image stops the build, so a typo can't slip through.

For the group photo, `hero.ceiling` in `content/photos.json` is the fraction of its height, measured from the top, that is only ceiling (0.18 now; the highest head starts at about 0.215). Wide screens crop that much and no more, and get margins beyond it. Measure it again if the photo changes. Crops marked `"frac": true` (the Yann LeCun tile is cut from the group photo) are fractions of the image, so they stay right when a larger copy of the same photo replaces it.

`assets-src/brand/og-logo.png` is the logo for `og.jpg`, rendered from `src/svg/logo-display.svg` (ink on transparent, 544px wide). Render it again if the logo changes.

## Build and look at it locally

Needs Node 18 or newer. Nothing to install.

```bash
npm run dev
```

That builds `dist/` and serves it at http://localhost:4321, on this computer only, with the same clean URLs, redirects and headers as Vercel. Other commands:

```bash
npm run build      # production build into dist/
npm run preview    # preview into preview/ (inlined CSS, JS and fonts; links end in .html). preview/index.html is a
                   # fragment for the Claude artifact viewer, which supplies the page frame; open the other pages directly.
BUILD_NOW=2026-11-07T12:00:00-05:00 npm run build   # pretend it is another date
ALLOW_MISSING=1 npm run build      # development only: placeholders for missing fonts and portraits instead of stopping
```

The build stops with a list of problems if content is invalid (including a talk time with the wrong offset), a photo or font is missing, or any internal link, anchor, icon or redirect target is broken.

## Deploy

Vercel reads `vercel.json`: build command `node tools/build.mjs`, output `dist/`, clean URLs, and permanent redirects from the old pages (`/meeting-materials` to `/speakers`; `/resources`, `/reading-lists` and `/reading` to the home page). Every branch pushed to GitHub gets its own preview URL. Merging into `main` publishes to aiclub.dartmouth.edu. Fonts are published under names that include a hash of their contents, so browsers can keep them for a year and still get a replaced font at once.

### Optional: rebuild every morning

A talk added before it happens appears in visitors' browsers once it has ended. Visitors with JavaScript off see it after the next build. To rebuild every morning anyway, create a deploy hook for `main` in Vercel (Project, Settings, Git, Deploy Hooks), save its URL in GitHub as the Actions secret `VERCEL_DEPLOY_HOOK`, and add `.github/workflows/rebuild.yml`:

```yaml
name: Daily rebuild
on:
  schedule:
    - cron: '17 10 * * *'   # 10:17 UTC, early morning in Hanover
  workflow_dispatch:
jobs:
  rebuild:
    runs-on: ubuntu-latest
    steps:
      - run: curl -fsS -X POST "$HOOK"
        env:
          HOOK: ${{ secrets.VERCEL_DEPLOY_HOOK }}
```

## Design rules

- **Colour.** Paper `#F4F4F1`, ink `#161616`, gray `#666662`, hairlines `#D9D9D4`. Never pure white or pure black. Dartmouth Green `#00693E` marks things you can act on (the Join links and button, link hover, keyboard focus, selection) and numbered markers. Nowhere else.
- **Type.** One family, two weights. Helvetica on Apple devices and TeX Gyre Heros (a free Helvetica clone) everywhere else, through the single family name `Club Sans` in `src/styles/site.css`.
- **Logo.** `src/svg/logo-display.svg` (hero size: tighter letter-spacing and leading) and `src/svg/logo-small.svg` (header and footer: looser, so the lines never touch). They are drawn outlines, so they look identical on every device. Never retype the logo as live text.
- **Arrow.** `src/svg/arrow-e.svg` and `arrow-ne.svg` are the only icons. → goes somewhere on this site; ↗ leaves it.
- **Motion.** One choreographed moment: the hand-off on the home page. Native scrolling, the browser's own cursor, nothing fading in on scroll. People who ask their device for reduced motion get the static layout.

## Folders

```
content/        what the site says (edit these)
src/pages/      one file per page
src/lib/        shared header, footer, layout and helpers
src/styles/     site.css
src/scripts/    site.js (hand-off, mobile menu, talks that have just happened)
src/svg/        logo lockups and arrows
public/         copied as-is: fonts, images, icons
tools/          build.mjs, serve.mjs, images.py
assets-src/     metadata-free originals of the photos, and the logo for og.jpg (not published)
```
